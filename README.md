# Vector Bench

Introduction to College Math，Project 1，Option 2。一个可交互网页：用向量决定一块屋顶太阳能板的朝向，并计算阳光有多正对玻璃。

页面是英文，方便按讲义提交。计算和三维箭头用的是同一套数值。

## 运行

```bash
npm install
npm test
npm run dev
```

打开 `http://localhost:3000`。

- `/` 情景和案例结果
- `/bench` 可调参数、屋顶三维、逐步计算
- `/instruction` 书面说明（200–400 词）和出处

## 案例

坐标：x 东，y 北，z 上，单位米。

- 角点 A = ⟨0, 0, 0⟩，B = ⟨3, 0, 0⟩，D = ⟨0, 4, 3⟩，C = ⟨3, 4, 3⟩
- 边 u = ⟨3, 0, 0⟩，v = ⟨0, 4, 3⟩
- 法向量 n = u × v = ⟨0, −9, 12⟩，面积 |n| = 15 m²
- 单位法向量 ⟨0, −3/5, 4/5⟩
- 太阳 s = ⟨0, −4, 3⟩
- n · s = 72，cos θ = 24/25，θ ≈ 16.26°
- 同样的太阳打在水平屋顶上只有 3/5，这块板是它的 8/5

实验台上还有两个预设：Flat roof（rise = 0）和 Sun behind（太阳从北侧来，点积为负）。
